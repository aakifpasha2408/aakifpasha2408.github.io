# Aakif Shaik — Professional Business Analytics Portfolio

A responsive single-page portfolio website using HTML, CSS and JavaScript. Includes the newly supplied professional portrait and five project case studies.

## Files
- `index.html` — page content and project case studies
- `styles.css` — responsive design and visual theme
- `script.js` — mobile navigation
- `assets/aakif-photo.jpg` — portrait image
- `assets/Aakif_Shaik_CV.pdf` — downloadable CV PDF

## Preview
Extract the ZIP and open `index.html` in a browser. For best local preview, use Visual Studio Code with the Live Server extension.

## Publish free with GitHub Pages
1. Create a public repository on GitHub, for example `aakif-shaik-portfolio`.
2. Upload the contents of this folder, including the `assets` folder.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will show the published website URL in the Pages settings.

## Check before publishing
- Confirm the email and LinkedIn details in `index.html`.
- The CV PDF is included and linked from the homepage and contact section; review the PDF before publishing.
- Add only verified GitHub links to your projects; this version does not invent project URLs. A previously supplied ESG repository URL was not working, so it has not been included.
- Review project figures against your final reports.
- The ESG chart is explicitly labelled as illustrative, not measured annual ESG data.
- Fraud metrics describe the project dataset, not guaranteed production performance.
- The blockchain report is identified as an academic proposal, not an HMRC-sponsored or implemented project.
- Power BI is described as workshop/training exposure.

## Customise
Edit content in `index.html` and styling in `styles.css`.
